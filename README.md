# PT Barbershop Coming Soon Website

Web public cho khach xem hien tai dang de trang Coming Soon / EST. 2027.

## Mo tren may

Mo file `index.html` bang Chrome/Edge la xem duoc ngay.

## Dua len hosting

Day toan bo thu muc nay len hosting tinh nhu Hostinger, Netlify, Render Static Site hoac GitHub Pages.

Neu dung chung voi bo POS Render, ten mien goc se mo web gioi thieu, con `/pos/` se mo app order/POS.

## Can sua thong tin

- Doi dia chi: sua dong `Xa Hau Nghia, Tay Ninh` trong `index.html`.
- Doi anh coming soon: thay file `assets/coming-soon-2027.jpg`.
- Doi mau/bo cuc: sua `styles.css`.

## Luu y

Trang public khong hien link app noi bo. App POS van mo rieng o `/pos/` tren cung ten mien.
