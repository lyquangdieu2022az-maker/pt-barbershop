Cach dua len Render dung cach:
1. Tao tai khoan hoac dang nhap Render: https://dashboard.render.com/
2. Dua thu muc du an nay len GitHub/GitLab/Bitbucket.
3. Trong Render, chon New + -> Blueprint.
4. Chon repo vua day len.
5. Render se doc file render.yaml trong thu muc goc.
6. Render se tao 2 thu:
   - Web Service: pt-barbershop-pos
   - Postgres database: pt-barbershop-db
7. Bam Apply de deploy.

Cau hinh da chuan bi san:
- Service name: pt-barbershop-pos
- Runtime: node
- Build command: npm install
- Start command: npm start
- Database: pt-barbershop-db

Sau khi deploy xong, Render se cap link dang:
https://pt-barbershop-pos.onrender.com

Ten mien:
- Link dang *.onrender.com la mien phi.
- Neu muon ten mien rieng dep nhu ptbarbershop.com hoac ptbarbershop.vn thi thuong phai mua ten mien.
- Render mien phi phan gan custom domain va SSL/HTTPS, nhung phi mua ten mien la cua nha cung cap ten mien.
- Co the dung tam link onrender.com de gui khach xem va cai PWA tren iPhone/Android.
